# M10 Quarto Website — Simple Source Version

This folder contains only the source files. Render it locally with:

```bash
cd M10-simple
quarto preview
```

Before submitting:

1. Replace `profile-placeholder.svg` with your photo.
2. Add your school name and previous education to `index.qmd`.
3. Replace the placeholder GitHub Pages and repository URLs in `index.qmd`.
4. Run `quarto render` and check the generated HTML.
5. Push the entire folder, including `_quarto.yml`, all QMD files, `styles.scss`, and the `projects/` folder, to GitHub.
